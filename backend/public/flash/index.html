Desk screen flasher

Flashes the Waveshare ESP32-S3-LCD-4.3 from Chrome or Edge on a computer, over USB. Nothing to install.

  1. Get the firmware

    GitHub → your desk-dashboard repo → Actions → newest green firmware run → Artifacts → download firmware and unzip it. It contains firmware-merged.bin.

    The file has your Wi-Fi password and device token built in, so it is never put on this website. It stays in your private GitHub repo and on your computer.

  2. Choose the file

  3. Connect and install

    Plug the board into this computer with a USB-C data cable (the port marked UART). The first time, you may need to hold BOOT while plugging it in.

    This browser can't talk to USB devices. Use Chrome or Edge on Windows, macOS or Linux. USB access needs HTTPS. Open this page via its https:// address.

    After installing, choose Logs & console in the same dialog to watch Wi-Fi, time, fetch and render messages.

Also works for Waveshare's own demo image (lvgl_Porting_No_Touch.bin) to check the board first.
